## 현재 구성

Systems Notebook을 OPS / SEC / AI의 단일 허브로 운영한다. 별도 AI ON-PREMISE 카드를 합치고 온프레미스 AI는 OPS와 AI에서 함께 찾는 주제로 다룬다. 기존 자기소개, Notebook 소개·메타 설명·푸터, 포트폴리오의 Systems Notebook 설명은 보존했다. 이 문구들은 사용자가 나중에 정하기로 한 범위다.

첫 7편은 논문별로 나뉘어 논지가 끊겼다. 사용자 피드백을 반영해 학습·데이터·추론에서 각각 하나의 문제를 끝까지 다루는 **긴 원고 3편**으로 통합하고, 평가기의 오류·문제별 회귀·독립 검수·구성 복원까지 보강했다. 공개 페이지는 원고 Markdown을 직접 읽어 정적으로 생성한다.

| 분야 | 범위                               | 등록 글 수 |
| ---- | ---------------------------------- | ---------: |
| OPS  | 구성, 배포, 관측, 복구, 모델 서빙  |         16 |
| SEC  | 인증, 권한, 프로토콜, 데이터 출처  |          6 |
| AI   | 모델, 학습, 평가, 데이터, 에이전트 |          7 |

고유 글은 21편이다. 기존 운영 자료 15편과 zkTLS 3편에 AI 3편을 추가했다. 중복 분류는 같은 URL을 여러 분야에서 찾게 하므로 분야별 수의 합은 고유 글 수와 다르다. 추론 시스템 원고는 OPS / SEC / AI에 함께 속한다.

기존 MLOps 12–15편은 OPS / AI에 함께 등록하고 기존 `/ko/notebook/ops/…` 주소를 유지한다. 예전 KO·EN `/work/local-ai-ops-notes/`는 한국어 AI 목록으로 이동한다. 영어 번역 원고는 등록하지 않았다.

## 근거와 직접 실행의 범위

출발점은 [교육 자료 페이지](https://astg.vercel.app/education/#/260903-choi-yejin)이며 주장과 연구 수치는 본문에 연결한 1차 자료와 대조했다. 음성 파일은 제공되지 않았다. 원고를 녹취록이나 강연자의 발언 재현으로 표시하지 않는다.

판매 표, 확률, 비용과 지연 시간은 작성자가 만든 설명용 가정이다. pass@k는 문제별 계산을 먼저 한 뒤 평균하며 생성과 선택을 구분한다. 논문 결과는 버전과 평가 조건을 유지한다. 비용·품질·시간 예제를 실제 시스템의 성능 예측으로 연결하지 않는다.

구성 복원 예제만 작은 코드를 직접 실행했다.

- 코드: `static/notebook/ai/release-replay.mjs`
- 결과: `static/notebook/ai/release-replay-result.json`
- 실행: `node static/notebook/ai/release-replay.mjs`
- 환경: Node.js v24.12.0, 추가 패키지·외부 API·실제 모델 없음.
- 확인: 모델 ID만 복원하면 입력 문맥이 다르고, 전체 예제 구성을 복원하면 입력과 구성의 SHA-256이 기준과 같다.

이 결과는 합성 자료의 입력 조립과 구성 식별자의 복원을 입증한다. 실제 모델 추론, 모델 가중치 배포, 응답 재현성, 외부 상태의 롤백을 입증하지 않는다. 원고와 공개 예제에도 같은 범위를 표시했다.

## 화면과 코드

어두운 바탕과 주황 강조, 선 중심 도식을 유지한다. 긴 본문과 고정 목차가 기본이며 작은 화면에서는 목차가 펼침 버튼으로 바뀐다. 23개 절은 고유 앵커를 갖고 세 원고를 하단에서 오갈 수 있다. 표는 자기 영역 안에서 가로로 스크롤하고 본문과 코드는 줄바꿈한다.

본문 조작 예제는 생성·선택 확률, 판매 표의 과제, 추가 전달 비용, 구성 복원의 네 가지다. 추론 원고에는 요청부터 응답까지 6개 역할의 단계 도식도 둔다. 홈의 OPS 8개 요소와 MLOps 9개 요소 도식은 보존하며, AI 대표 글에서 새 추론 글과 기존 MLOps 플랫폼 글을 선택한다. 단계 버튼은 모션을 꺼도 설명을 갱신한다.

주요 코드 위치:

- 원고·메타데이터·렌더링: `src/lib/notebook/ai/`
- 공개 라우트: `src/routes/[locale=locale]/notebook/ai/[slug]/`
- 통합 목록: `src/lib/notebook/notebook.ts`
- 흐름도: `src/lib/notebook/components/FlowPreview.svelte`, `flow-preview.ts`, `detailed-preview.ts`

## 검증과 배포

원고 수치의 산술과 논문 원문을 대조했다. 최종 변경에서 단위 테스트 16개 파일·107개, Svelte 진단 오류·경고 0, 정적 사이트 빌드와 변경 범위의 ESLint·Prettier 검사를 통과했다. 생성된 세 페이지의 23개 절과 내부 링크 136개를 검사했고 구성 복원 코드를 재실행해 공개 JSON과 같은 결과임을 확인했다.

로컬 브라우저에서 AI 필터 직접 진입, 새 원고 검색과 삭제, 글 사이 이동, 목차 앵커, 네 예제의 계산·초기화·키보드 조작을 확인했다. 좁은 화면의 본문·결과 문장과 페이지에 가로 넘침이 없었고 모션을 꺼도 도식 단계를 바꿀 수 있었다. 배포는 기존 GitHub Actions의 Azure Static Web Apps 경로를 사용한다. `main`에 반영한 커밋의 워크플로 성공과 운영 페이지의 본문·조작 결과를 확인해야 발행 완료로 판단한다.
